# Plan: Fix calculateDeal() to work without financing options

## Problem

After AC3/AC4 implementation, `calculateDeal()` was changed to only calculate for financing options. When editing discounts (Other Discount, Trade-in, Eco Bonus) in the Asset tab without financing options, the API is NOT called.

## Root Cause

The `calculateDeal()` method now uses `_buildTargetDeals()` which filters only financing options with `salesQuoteId` and `bareme`. If no financing options exist, it returns early without calling the API.

## Solution

Add fallback in `calculateDeal()` to calculate the main asset deal when no financing options are available.

## Changes

### File: `features/asset/stores/assets.ts`

In `calculateDeal()` method (around line 732):

**Current:**
```typescript
async calculateDeal() {
  const financingStore = useFinancingStore();
  const targetDeals = this._buildTargetDeals(financingStore);
  
  // No valid deal to calculate
  if (!targetDeals.length) return;
  
  // ... calculate for each financing option
}
```

**Fixed:**
```typescript
async calculateDeal() {
  this.isCalculating = true;
  this.calculationError = null;

  try {
    const financingStore = useFinancingStore();
    const targetDeals = this._buildTargetDeals(financingStore);

    if (targetDeals.length > 0) {
      // Calculate for financing options (existing logic)
      // ...
    } else if (this.salesQuoteId) {
      // Fallback: calculate main asset deal directly
      const { payload, calculationData } = this._buildDealCalculationRequest({});
      
      const { api } = useApi();
      const response: any = await api(
        `/api/deals/${this.salesQuoteId}/calculations`,
        {
          method: "POST",
          body: { payload, calculationData },
          notifyOnError: false,
        },
      );
      
      this._applySelectedOptionPricing(response);
    }
  } catch (e: any) {
    console.error("calculateDeal failed", e);
    this.calculationError = e?.errorDescription || e?.message || "Calculation failed";
    this._showErrorNotification(this.calculationError);
  } finally {
    this.isCalculating = false;
  }
}
```
