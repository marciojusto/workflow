# LangChain4J Resources

## Knowledge

- [LangChain4J Official Documentation](https://langchain4j.com/)
  The canonical reference. Use for: API surface, architecture overview, getting started guides.
- [LangChain4J GitHub Repository](https://github.com/langchain4j/langchain4j)
  Source code and examples. Use for: implementation details, version-specific features, working snippets.
- [LangChain4J Examples](https://github.com/langchain4j/langchain4j-examples)
  Runnable examples covering RAG, agents, tools, streaming, and more. Use for: copy-paste starting points.
- [Kilo.ai Documentation](https://kilocode.ai/docs)
  LLM provider API reference and SDKs. Use for: authentication, model IDs, request/response formats.
- [LangChain4J Spring Boot Starter](https://github.com/langchain4j/langchain4j-spring)
  Integration guide for Spring Boot applications. Use for: wiring LangChain4J into Spring projects.
- [LangChain4J Observability / OpenTelemetry Guide](https://langchain4j.com/docs/observability/)
  Official guide to tracing and metrics. Use for: setting up OTEL exporters, Jaeger, and Micrometer.
- [OpenTelemetry Java Documentation](https://opentelemetry.io/docs/instrumentation/java/)
  General OTEL instrumentation reference. Use for: configuring agents, exporters, and sampling.
- [LangChain4J Token Usage and Cost Tracking](https://langchain4j.com/docs/token-usage/)
  How to capture token counts and estimate cost per request. Use for: billing dashboards and per-user quotas.
- [LangChain4J RAG Debugging](https://langchain4j.com/docs/rag/debugging/)
  Inspecting retrieval quality, embedding distances, and chunk relevance. Use for: tuning chunk size and embedding models.
